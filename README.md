# 🚁 DRAC AI Traffic System

AI-powered system for detecting traffic violations using aerial monitoring.

## Features
- Object Detection using YOLO
- Traffic Behavior Classification (Drifting, Wrong Way, Normal)
- Interactive Dashboard
- Image Upload & Camera Capture

## Tech Stack
- Python
- TensorFlow
- YOLO (Ultralytics)
- Streamlit

## Demo
Upload or capture an image to analyze traffic behavior in real-time.
